# Changelog — 2026-08-02

## Stage 1: Foundation

### Created
- Repository structure: `BM176/` with `Source/GUI/`, `Source/Components/`, `changelog/`
- `CMakeLists.txt` — JUCE 8 VST3 target, C++17, links all Source files
- `Source/GUI/BM176Geometry.h` — design coordinate constants (1920×540), scaling helpers
- `Source/GUI/BM176Colours.h` — procedural palette (graphite panel, dark metal, black plastic, cream, orange, white text)
- `Source/GUI/BM176LookAndFeel.h/.cpp` — base LookAndFeel_V4 subclass
- `Source/Components/BMPanel.h/.cpp` — procedural panel: rack ears, metal chassis, inner powder coat panel, bevels, 4 screws, drop shadows
- `Source/PluginProcessor.h/.cpp` — minimal AudioProcessor, stereo I/O, empty processBlock
- `Source/PluginEditor.h/.cpp` — fixed 1920×540 editor, AffineTransform scaling, resizable 0.5x–2.0x
- `Source/GUI/BM176Editor.h/.cpp` — orchestration root, owns BMPanel

### Architecture decisions
- Editor applies `AffineTransform` at the `BM176Editor` level — all child painting stays in design coordinates
- `BMPanel` renders everything procedurally via `juce::Graphics`, `juce::Path`, `juice::ColourGradient`, `juce::DropShadow`
- Geometry constants live in `bm176` namespace in dedicated header (no magic numbers)
- Colours live in `bm176` namespace in dedicated header (no inline hex values in paint code)
- BM176Editor will become the container for all future control components

## Stage 2–5: Controls + Layout

### Stage 2: Knob System
- `Components/BMKnob.h/.cpp` — base knob: outer rubber ring, 52-ridge knurling, gradient body, plastic cap, white indicator line, drop shadow. Value 0-1, drag handling, configurable angle range.
- `Components/BMDiscreteKnob.h/.cpp` — stepped variant, snaps to N detents on drag
- `Components/BMContinuousKnob.h/.cpp` — smooth variant, continuous drag

### Stage 3: Switch System
- `Components/BMToggleSwitch.h/.cpp` — 2-position metal lever toggle: threaded bushing, nut, lever with ball tip, label support. Used for Interstage, Attack ON/OFF.
- `Components/BMThreeWaySwitch.h/.cpp` — 3-position lever switch. Used for Meter mode (IN/GR/OUT).

### Stage 4: VU Meter
- `Components/BMVU.h/.cpp` — procedural analog meter: metal bezel, cream face, dB scale (-20 to +3), orange needle with pivot, glass reflection overlay, smoothed needle animation.

### Stage 5: Complete Layout
- All controls placed in `BM176Editor::resized()` using descriptor coordinates from `ua176.yaml`
- Layout mapping:
  - **Ratio** (0.135, 0.29) — 5-position rotary switch, 120° sweep
  - **Sidechain HP** (0.135, 0.73) — 6-position, greyed (unmodelled)
  - **Input** (0.260, 0.55) — 21-position stepped, large knob
  - **Vernier In** (0.352, 0.76) — greyed (unmodelled)
  - **Threshold** (0.400, 0.52) — continuous, small knob
  - **VU Meter** (0.43–0.64, 0.10–0.60) — analog meter
  - **Interstage** (0.682, 0.50) — toggle switch
  - **Attack ON/OFF** (0.682, 0.72) — toggle switch, placed under Interstage (per user request)
  - **Attack** (0.725, 0.31) — continuous, small knob
  - **Output** (0.815, 0.55) — 21-position stepped, large knob
  - **Vernier Out** (0.900, 0.76) — greyed (unmodelled)
  - **Release** (0.915, 0.31) — continuous, small knob

### Design decisions
- Knobs render procedurally with composition, not via LookAndFeel::drawRotarySlider
- Greyed controls (sidechain_hp, vernier_in, vernier_out) use setAlpha(0.45)
- Attack ON/OFF positioned under Interstage at same x=0.682, not under Attack (user directed)
- VU meter uses exponential smoothing (0.3 blend factor) for needle animation

### Additional components + labels
- `Components/BMLED.h/.cpp` — illuminated LED indicator (green/orange/red/yellow), glow gradient, power/comp LEDs placed top-left
- `Components/BMJackSocket.h/.cpp` — metal jack socket: bezel ring, dark center hole, shadow. INPUT, HI-Z, OUTPUT jacks placed at edges
- `BM176Editor::paint()` — draws knob labels, tick marks, scale values, slow/fast markers, bma logo + "LIMITING AMPLIFIER" + "BM 176" branding
- Knob scales: Ratio (1.5–12), Input/Output (40–0 stepped), Attack (dots 2–9), Release, HP Filter (OFF–200hz)
- 32 source files total, all compile clean against JUCE 8
